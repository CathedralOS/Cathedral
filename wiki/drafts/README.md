# Drafts

Temporary investigations, comparison notes, and migration plans live here.
Drafts do not define Cathedral contracts.

Each draft should state its purpose, the permanent owner it may inform, and the
condition under which it can be deleted. Promote accepted rules to the
[specification](../spec/README.md), concrete candidate behavior to
[proposals](../proposals/README.md), and durable rationale to the relevant
design chapter. Remove obsolete residue rather than letting drafts become a
second specification.
