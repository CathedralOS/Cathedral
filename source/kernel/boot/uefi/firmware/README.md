# Firmware ownership

[firmware.omg](firmware.omg) greets through the firmware console, discovers the
loaded-image geometry and enters [ownership](ownership/ownership.omg). That
transaction refreshes the map/key together, validates candidates, exits Boot
Services, grants the two conserved roots, publishes the handoff and transfers
them to the build-selected continuation. Its serial ownership report is bounded.

The [memory-map package](memory_map/firmware_root.omg) checks a retained map
against numeric root geometry; the kernel lab uses it after handoff. These
checks do not manufacture backing or lifetime authority. Firmware provenance,
selected provider admission and successful exit remain separate obligations.

The ownership transaction still contains its older descriptor walk and serial
number formatting. Refactor those once full compiler checking can verify the
retained boundary/ownership contracts; current blockers are in the work handoff.
